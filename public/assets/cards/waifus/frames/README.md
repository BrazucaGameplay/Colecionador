# Molduras de raridade das waifus

Reservado para as cinco molduras finais, fornecidas pelo projeto:

- `common.webp` — Comum; símbolo círculo.
- `rare.webp` — Rara; símbolo diamante.
- `epic.webp` — Épica; símbolo estrela.
- `legendary.webp` — Lendária; símbolo coroa.
- `mythical.webp` — Mítica; símbolo estrela celestial.

## Requisitos

- Arquivos independentes da ilustração da personagem.
- PNG ou WebP com transparência real.
- Mesma tela de referência, proporção e área interna útil entre as cinco molduras.
- Centro transparente para a arte original aparecer integralmente.
- Símbolo da raridade incorporado na própria moldura, em posição consistente.
- Não incluir nome da waifu, qualidade, atributos ou textos variáveis.
- Não criar molduras provisórias. Os arquivos finais serão fornecidos pelo usuário.

A moldura é uma camada visual; nunca modificar ou recomprimir a arte original para encaixá-la.
