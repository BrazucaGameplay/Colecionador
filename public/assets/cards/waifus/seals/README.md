# Selos de qualidade das waifus

Reservado para os cinco selos finais, pequenos e independentes das molduras de raridade:

- `plebeia.webp`
- `nobre.webp`
- `dama.webp`
- `princesa.webp`
- `rainha.webp`

Cada selo deve conter o nome completo da qualidade, com leitura clara em telas mobile. Os cinco arquivos devem compartilhar dimensões, área de respiro e ponto de ancoragem.

O selo será sobreposto como camada independente à carta composta. Não incluir símbolos ou elementos que confundam qualidade com raridade. Não criar arquivos provisórios.
