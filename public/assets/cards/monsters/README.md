# Cartas de monstros

Uma pasta por ID estável de espécie. Cada pasta contém a carta estática oficial em `<species-id>/card.<ext>`. Slime: `slime/card.jpg`. As 11 cartas fornecidas estão organizadas, uma por pasta.

Não misturar cartas com spritesheets de gameplay, que continuam em `public/assets/monsters/`.
